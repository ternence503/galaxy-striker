## 💾 下載到電腦玩（離線也能玩）

### 第一步：下載遊戲

點右上角綠色的 **`Code`** 按鈕 → 選 **`Download ZIP`**

![下載示意](https://docs.github.com/assets/cb-47677/mw-1440/images/help/repository/code-button.webp)

### 第二步：解壓縮

找到下載的 `galaxy-striker-main.zip`，雙擊解壓縮。

### 第三步：啟動遊戲

| 系統 | 做法 |
|------|------|
| **Mac** | 雙擊 `啟動遊戲_Mac.command`<br>（第一次開啟：右鍵 → 打開 → 打開） |
| **Windows** | 雙擊 `啟動遊戲_Win.bat` |
| **其他** | 用任何瀏覽器直接開啟 `index.html` |

## ⚡ 道具寶石

吃到地圖上掉落的寶石可以改變武器：

| 寶石 | 效果 |
|------|------|
| 🔴 紅 | 雙管機槍 — 左右各一門炮 |
| 🟢 綠 | 散彈槍 — 五方向同時射擊 |
| 🔵 藍 | 雷射 — 貫穿全螢幕光束 |
| 🟡 黃 | 導彈 — 自動追蹤敵機 |
| 🟣 紫 | 炸彈 — 清除畫面所有敵人 |
| 🟠 橘 | 護盾 — 暫時無敵 |
